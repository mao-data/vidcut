# AI 編輯動畫層（方案 A）— old-coder SPEC

2026-08-02。設計（效果、節奏、觸發規則）已於對話中經使用者核准；使用者指示
「直接用 /old-coder 開工」→ 本 SPEC 在該授權下逕行執行，EVIDENCE 如實記載。
Tier 2（UI 功能；不碰資料持久面）。

## 目標

AI 經 MCP 編輯時，變更以動畫呈現而非瞬跳：移動滑行（彈簧）、新增骨牌進場、
被改項紫色光暈衰減、視窗外變更先平滑捲動、Activity 新列滑入。
人的操作**零改變**（拖曳 1:1 跟手）；`prefers-reduced-motion` 全部退化為瞬切。

## 節奏（已核准）

移動 0.3s spring（cubic-bezier(.3,1.36,.4,1)）／進場 0.25s＋40ms stagger／
光暈 1s 衰減／捲動 0.4s。全程 CSS keyframes/transition，GSAP 只負責捲動 tween。

## 可執行驗收條件

### A. `fx/aiPatches.ts` — 純函式 `analyzeAiPatches(patches, prevDoc, nextDoc)`

1. 整組替換 captions（2 新 id＋1 改內容＋1 原封不動）→ `added=[新 id×2]`、
   `touched=[改內容 id]`，原封不動者兩者皆非。
2. 單欄位 patch `['tracks','captions',0,'start']` → `touched=[nextDoc 該 index 的 id]`。
3. 主軌 reorder（多個 index 被 replace）→ 位置變了的 clip id 進 `touched`。
4. `op:'add'` 於 `['tracks','overlays',1]` → `added=[value.id]`。
5. `op:'remove'` → 被刪 id 不出現在 added/touched（不對不存在的元素做動畫）。
6. 回傳 `minStart`：added∪touched 中最早的時間軸起點秒數（無可算時 null）——
   自動捲動的目標。clip 用累積起點、caption/audio 用 start、overlay 用視窗起點。
7. 與 tracks 無關的 patch（如 render.status）→ 全空結果。

### B. `stores/editFx.ts`

8. `trigger(fx)` 後 `window=true`、`stamp` 遞增、ids 可查。
9. 1.6 秒後自動清空（fake timers）；清空觸發訂閱者。
10. 窗內再 trigger → 合併 ids、計時器重置（連發不斷窗）。

### C. project store 接線

11. `applyServerMsg` 收到 `source:'ai'` 的 patch → editFx 被 trigger 且 ids 正確。
12. `source:'human'` 的 patch → editFx **不**被 trigger。

### D. Timeline 呈現

13. fx window 內：四條軌的容器有 `ai-anim` class。
14. `touched` 內的 chip 有 `fx-glow-a|b` class（依 stamp 奇偶交替，動畫可重播）。
15. `added` 內的 chip 有 `fx-enter` class 且 `--fx-i` 依序遞增（骨牌 stagger）。
16. **人拖曳中（drag.current 非空）→ `ai-anim` 不得出現**（1:1 跟手不可破壞）。
17. 純函式 `scrollTargetFor(minPx, scrollLeft, clientWidth)`：目標在可視範圍內
    → null；在範圍外 → 回傳讓目標置於約 1/3 處的新 scrollLeft（≥0）。

### E. Player／Activity

18. `added` 中的 caption/overlay 在預覽畫面掛 `fx-enter`。
19. Activity 列：ts 距今 <3s 者掛 `fx-slidein`。

### F. 不變量（must NOT）

- 既有 283 測試零新增失敗；伺服器端零改動；WS 協議零改動。
- 人拖曳路徑行為完全不變（見 16）。
- reduced-motion：theme.css 以 media query 全域關閉 fx——**不寫單元測試**
  （jsdom 不套用 media query），列為 EVIDENCE 的 skipped-with-reason，由使用者親驗。
