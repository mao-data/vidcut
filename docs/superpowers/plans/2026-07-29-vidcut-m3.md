# vidcut M3「AI 接上」Implementation Plan

> 承接 M2（tag `m2-done`）。延續 TDD、命令層單一路徑、每任務一 commit。

**Goal:** 讓任何 MCP client（Claude Code…）透過 `/mcp` 剪片：讀專案、匯入素材、排時間軸、逐項編輯，並在關鍵步驟 `request_review` 暫停等人類在瀏覽器核准。完成「AI 剪、你看著調、AI 繼續」的閉環（渲染除外，M4）。

**Architecture:** 用 `@modelcontextprotocol/sdk@1.30.0`（穩定 v1；v2 elicitation 之後用官方 codemod 遷移）。MCP Streamable HTTP 掛在既有 server 同一 port 的 `/mcp`（stateless：每請求 fresh McpServer+transport，closure 引用共享 ProjectStore）。**寫入工具全部重用 M2 的 `applyCommand`（source='ai'）**，額外套兩層守衛：審核進行中擋 AI 寫入（spec §6.3）、`ifVersion` 過期偵測（spec §4.1）。request_review 用「阻塞等待 + UI 核准 + 保活 + 逾時 + 退回回滾」模式（elicitation URL mode 列為 HANDOFF 的後續增強，因無法自動驗證 Claude Code 連線）。

**Tech Stack:** 延續 + `@modelcontextprotocol/sdk` 1.30.0、`zod` 3。

## Global Constraints

延續 M1/M2。新增：

- **MCP 寫入工具一律 source='ai'**，且：(a) `store.doc.review !== null` 時回錯誤（審核中）；(b) 帶 `ifVersion` 且與 `store.version` 不符時回錯誤「使用者已修改，請 get_feedback 後重試」。
- **讀取工具回裁剪視圖**，避免超過 Claude Code 25k token 輸出上限；媒體回 URL 不回 base64。
- **request_review 阻塞期間**每 20s 送 progress notification 保活；預設 900s（15 分）逾時。
- MCP 只在 `127.0.0.1`（沿用既有綁定）。

## Tasks

### Task 1: aiWrite 守衛 + EditorContext
- `aiWrite(store, cmd, ifVersion?)`：review 中 → 錯誤；ifVersion 不符 → 錯誤；否則 `applyCommand(store,'ai',cmd)`。
- `EditorContext`：holder，`set(data)`/`get()`。
- 測試：review 中擋寫、ifVersion 不符擋寫、正常通過。commit `feat(m3): aiWrite guards + editor context holder`

### Task 2: ReviewManager
- `request(store, {summary, focus})`：mutate 設 `doc.review`；回 `{id, promise}`；保活計時器 + 逾時。
- `resolve(store, id, outcome, note?)`：清 `doc.review`；outcome==='rejected' → 回滾到 `sinceVersion`（undo count = version−sinceVersion）；resolve promise。
- 測試（不含真計時器等待，逾時用可注入的短值）：request→resolve approved 回正確；rejected 回滾 AI 變更；未知 id resolve 無效。commit `feat(m3): review manager (request/resolve/reject-rollback/timeout)`

### Task 3: MCP server + 工具註冊 + mount
- `createMcpServer(deps)`：註冊全部工具。
- `mountMcp(app, deps)`：`/mcp` stateless。
- 測試：InMemoryTransport + Client 連線，呼叫 get_project / import_media（真 ffmpeg）/ set_timeline / update_clip（經 aiWrite）/ get_editor_context。commit `feat(m3): mcp server + tool registry + /mcp mount`

### Task 4: request_review 工具 + WS reviewResolve + get_frame
- request_review 工具接 ReviewManager；WS `{type:'reviewResolve'}` → resolve。
- get_frame 工具 → extractFrame。
- 測試：in-process 呼叫 request_review（背景），經 ReviewManager.resolve 模擬 UI 核准，assert 回 approved + humanChanges；get_frame 產出 jpg。commit `feat(m3): request_review tool + reviewResolve + get_frame`

### Task 5: UI 審核條 + context 回報
- UI 送 `{type:'context'}`（選取/playhead 變化時）。
- 審核條：`doc.review` 非 null 時頂部顯示 summary + 核准/退回/留言按鈕 → 送 `reviewResolve`。
- commit `feat(m3): ui review bar + editor-context reporting`

### Task 6: M3 驗收
- in-process 全工具煙霧測試綠。
- 手動（HANDOFF 記步驟）：`claude mcp add --transport http vidcut http://127.0.0.1:3845/mcp`，在 Claude Code 內請 AI 排片 + request_review，UI 核准。
- typecheck + 全測試綠。tag `m3-done`。

## 驗收後
更新 HANDOFF（含 Claude Code 註冊指令、elicitation 後續增強）。進 M4。
