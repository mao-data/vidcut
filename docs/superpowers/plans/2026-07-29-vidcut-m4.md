# vidcut M4「渲染」Implementation Plan

> 承接 M3（tag `m3-done`）。延續 TDD、每任務一 commit。

**Goal:** 從 `project.json` 用 Node 原生 ffmpeg 輸出 1080×1920 成品 mp4（影片片段 + overlay PNG + 音訊混音），AI 與 UI 都能觸發，含進度回報。

**Architecture:** `server/src/render.ts` 把 project.json 直譯成一條 ffmpeg `filter_complex`：每片段 input-level `-ss/-t` 精確剪（一律重新編碼，禁 `-c copy`，spec §8.2）→ scale/pad 到畫布 → concat；overlay PNG 以 `overlay` 濾鏡按時間 enable 疊上；音訊有聲用片段聲音、無聲補 `anullsrc` 再 concat。captions 用 `drawtext`——但**本機 ffmpeg 無 libfreetype**，故 runtime 偵測，可用才燒、否則跳過並回報（重度文字走 overlay PNG，與 ranking-video-generator 的 make_overlays.py 一致）。進度解析 ffmpeg `-progress`，經 store.mutate 廣播。

**Tech Stack:** 延續。無新依賴。

## Global Constraints

延續。新增：

- 渲染一律對**原始素材**（非 proxy）重新編碼；**禁 `-c copy`**（spec §8.2 音畫對齊教訓）。
- 輸出固定 `1080×1920`，`libx264 -crf 20 -preset medium` + `aac 192k` + `+faststart`。
- 無 drawtext 時字幕不燒錄，`render` 回 `captionsBurned:false` 並在訊息中說明——不得靜默假裝已燒。

## Tasks（已執行）

### Task 1: render 核心 + 偵測

- `hasDrawtext()`：runtime 偵測（快取）。
- `buildRenderArgs(project, dir, out, {hasDrawtext})`：純函數，回 ffmpeg 參數 + totalDuration + captionsBurned。可單元測試 filtergraph 結構。
- `render(store, dir, stamp)`：跑 ffmpeg + 解析 `-progress` 更新 `store.render`。
- 測試：buildRenderArgs 結構（input 數、concat、anullsrc、overlay 位置、captions 依 drawtext）；整合測試真的渲染 demo → probe 1080×1920 + 有音軌 + 時長。
- commit `feat(m4): render pipeline (clips+overlays+audio, drawtext-detected captions)`

### Task 2: render 工具 + WS 觸發 + UI

- MCP `render` 工具 → `render()`；審核中擋。
- WS `{type:'render'}` → 非渲染中才啟動；進度經 store 廣播。
- UI `RenderBar`：渲染鈕 + 進度條 + 成品連結。
- 驗證：MCP HTTP 呼叫 render → 產出檔 + 回 URL。
- commit `feat(m4): render tool + ws render trigger + ui render bar`

## 已知限制（記入 HANDOFF）

- **字幕 burn-in**：本機 ffmpeg 無 drawtext，captions 不燒。要燒錄二選一：(1) `brew reinstall ffmpeg`（若 bottle 含 freetype）；(2) 把 caption 也 PNG 化（沿用 make_overlays.py / Pillow），走 overlay 軌——跨機器最穩，建議路線。
- 音訊目前僅片段原聲 concat；旁白/BGM amix 與 ducking 為後續（AudioItem 型別已預留）。
- 轉場/濾鏡/keyframe 未做（spec 第一版非目標）。
